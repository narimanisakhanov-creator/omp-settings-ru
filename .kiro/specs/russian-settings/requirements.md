# Требования: omp-settings-ru

Назначение: русский перевод штатной панели настроек OMP, распространяемый как отдельный открытый плагин.

Границы: только панель `/settings`. Перевод статистики, остального интерфейса и ответов моделей не входит в этот выпуск. Технические идентификаторы, команды и значения конфигурации сохраняются. Совместимость сначала проверяется на OMP 18.6.1 под Windows; поддержка других версий и ОС не объявляется без проверки.

### Requirement 1: Русский перевод настроек

**Objective:** Пользователь понимает назначение настройки без перевода английского текста вручную.

#### Acceptance Criteria

1. When пользователь открывает панель настроек с включённым русским переводом, the Plugin shall показывать русские названия всех доступных для перевода настроек проверенной версии.
2. When пользователь просматривает описание настройки, the Plugin shall показывать русское описание с сохранением технического смысла исходного текста.
3. When настройка содержит предупреждение о последствиях действия, the Plugin shall сохранять его смысл и степень опасности в русском переводе.
4. If текст или настройка неизвестны плагину, the Plugin shall оставлять исходный текст без выдуманного перевода.
5. When пользователь ищет переведённое название настройки на русском, the Plugin shall позволять найти соответствующую настройку средствами панели.

### Requirement 2: Сохранность поведения

**Objective:** Перевод меняет отображение, а не работу OMP.

#### Acceptance Criteria

1. The Plugin shall сохранять идентификаторы, типы, допустимые значения и обработчики настроек без изменений.
2. When пользователь меняет настройку через переведённую панель, the Plugin shall сохранять тот же результат, что и исходная панель.
3. The Plugin shall оставлять пути, имена моделей, имена провайдеров, секреты и пользовательские данные без перевода.
4. The Plugin shall не менять установленный исполняемый файл OMP.
5. The Plugin shall не изменять конфигурацию AGGG и существующие назначения моделей.

### Requirement 3: Переключение и восстановление

**Objective:** Пользователь может вернуться к исходным текстам без переустановки OMP.

#### Acceptance Criteria

1. When пользователь выбирает английский язык средствами плагина, the Plugin shall восстанавливать исходные тексты в текущем процессе.
2. When пользователь снова выбирает русский язык, the Plugin shall включать перевод без повторной установки.
3. When пользователь несколько раз включает один и тот же язык, the Plugin shall не накапливать повторные изменения интерфейса.
4. When пользователь удаляет плагин штатным способом и запускает новую сессию, the Plugin shall не оставлять изменений в исходной панели OMP.
5. The Plugin shall не записывать выбор языка в пользовательскую конфигурацию без отдельного согласия; для этого выпуска русский включается при загрузке расширения.

### Requirement 4: Совместимость и отказ

**Objective:** Обновление OMP не должно приводить к незаметному повреждению панели.

#### Acceptance Criteria

1. When плагин запускается на проверенной версии OMP, the Plugin shall загружать русский перевод без ошибок.
2. If необходимая для перевода структура панели несовместима, the Plugin shall оставлять исходные тексты без частично применённых изменений.
3. If перевод не может быть применён безопасно, the Plugin shall сообщать пользователю причину отказа без раскрытия личных данных.
4. The Plugin shall иметь проверку изменений исходных текстов, позволяющую сопровождающему обнаружить добавленные, удалённые и изменённые настройки.

### Requirement 5: Приватность и открытое распространение

**Objective:** Другие пользователи устанавливают плагин без доступа к данным автора.

#### Acceptance Criteria

1. The Plugin shall выполнять перевод локально без сетевых запросов и телеметрии.
2. The Plugin shall не читать ключи доступа, содержимое сессий и личные файлы ради перевода.
3. The Release shall содержать только файлы проекта, без личных конфигов, сессий и абсолютных путей компьютера автора.
4. Where используется заимствованный код, the Release shall сохранять требуемые лицензией уведомления об авторстве.

### Requirement 6: Поддержка проекта

**Objective:** Владелец может обновлять перевод и выпускать новые версии самостоятельно.

#### Acceptance Criteria

1. The Release shall содержать инструкции установки, удаления, переключения языка и проверки совместимости.
2. The Release shall содержать перечень реально проверенных версий OMP и платформ.
3. The Release shall содержать воспроизводимые проверки полноты перевода и сохранности поведения панели.
4. The Release shall содержать порядок обновления исходных текстов и выпуска новой версии.
5. When проект готовится к публичной публикации, the Review Process shall проверить лицензии, отсутствие личных данных и результаты запуска в установленном OMP.
