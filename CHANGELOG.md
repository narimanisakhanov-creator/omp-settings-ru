# изменения

## [0.1.0](https://github.com/narimanisakhanov-creator/omp-settings-ru/releases/tag/v0.1.0) — 2026-10-06

- отдельное расширение русского перевода штатного `/settings` OMP 18.6.1: 398 настроек, описания, предупреждения и статические варианты.
- `/settings-language ru|en` и выбор без аргументов; язык не сохраняется в конфиг. основной сессии принадлежит перевод; дочерний shutdown его не снимает.
- SHA-256 исходных метаданных, неизвестный/изменившийся источник остаётся английским. безопасный отказ при несовместимости, полный план дескрипторов и восстановление с защитой сторонних изменений.
- незавершённый rollback сохраняет recovery handle; en и main shutdown повторяют восстановление вместо ложного сообщения об успехе.
- динамические клавиши сохраняются через проверенные шаблоны; отображаемые options отделены от общих метаданных команд.
- закреплены Bun 1.3.14, TypeScript 5.9.2 и host baseline 18.6.1; добавлены покрытие/drift, smoke реестра и изолированный smoke штатной панели, CI Windows/Linux.
- сохранены MIT и copyright 2026 Elazer для адаптированного механизма `omp-settings-zh`. Stats, PATH-обёртки и autocomplete не перенесены.

### фактически проверено

Windows x64, установленный OMP 18.6.1: все 398 исходных хешей совпали с пакетами baseline; загрузка расширения, русский поиск «дальтоников», bool-изменение сохранило `colorBlindMode: true` в отдельном профиле; английское восстановление сохранило значение. выбор языка без аргументов вернул русский; статические варианты «Набор символов» показали русские описания. ни один запрос модели не отправлялся.

автоматические проверки: строгий TypeScript, 45 доменных тестов / 175 проверок, покрытие 398/398, drift 0; три ru/en цикла реестра (1785 мутаций на цикл), дескрипторы/исходные option-объекты восстановлены; smoke настоящего компонента панели проверяет поиск, bool/enum-редактирование оригинальных значений, main/child и shutdown. read-only ревью механизма и всего каталога выполнено; обязательные замечания исправлены и повторно проверены. состав пакета: 21 файл, включая SECURITY.md; проверка разрешённого состава и известных признаков секретов прошла; это не гарантия обнаружения любого секрета.

`plugin link` и последующая загрузка без `-e` проверены в одноразовом профиле; doctor: 3 ok, 1 warning об отсутствующем npm manifest, 0 errors. после uninstall новая сессия показала английскую панель и прежнее bool-значение. удаление менеджером потребовало Bun в PATH только дочернего процесса; глобальный PATH не менялся.

установленная панель Linux/macOS не проверена. baseline этих платформ выведены из исходных веток, не из прогона ОС. проверки CI отделены от подтверждения установленной панели; результаты доступны в [GitHub Actions](https://github.com/narimanisakhanov-creator/omp-settings-ru/actions).
