# частые вопросы

## установка

**менеджер просит `bun`, которого нет.** установи официальный Bun и повтори команду. глобальный PATH менять не нужно — установщик кладёт бинарь в `~/.bun/bin`:

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
omp plugin install git+https://github.com/narimanisakhanov-creator/omp-settings-ru.git#v0.1.0
```

**установка висит на `Resolving dependencies`.** при холодной установке менеджер тянет зависимости хоста — это несколько минут, не прерывай процесс. повторный запуск после обрыва может упереться в повреждённый git-кэш bun (`ENOTEMPTY`, `IntegrityCheckFailed`): удали каталог кэша внутри своего HOME (`.bun/install/cache`) и запусти установку заново.

**ставлю не в тот профиль.** команда без `--profile` ставит в активный профиль. для отдельного профиля: `omp --profile <имя> plugin install …`.

## язык и поведение

**панель осталась английской после установки.** перевод применяется при старте сессии. открой новую сессию и зайди в `/settings`.

**переключил язык, но панель не изменилась.** закрой `/settings` (Esc) и открой заново — панель строит строки при открытии.

**почему вкладки и группы остались английскими.** переводятся только названия, описания, предупреждения и подписи статических вариантов настроек. вкладки, группы, подсказки навигации и динамические списки хоста — нет. это осознанная граница, см. [architecture.md](architecture.md).

**часть строк на английском.** так задумано: неизвестные плагину настройки и изменившиеся исходные строки остаются английскими, а не переводятся наугад. сообщи о них в issue — добавим в следующем выпуске.

**`/settings-language` без аргументов ничего не делает.** команда открывает диалог выбора языка. если диалог не появился, значит команда ушла в строку поиска открытой панели — закрой её через Esc и повтори из промпта.

## совместимость и откат

**плагин отказался включаться с предупреждением.** проверяется только OMP 18.6.1. на другой версии перевод пропускается целиком, сессия продолжает работать на английском. текст предупреждения — в [glossary.md](glossary.md) не входит, он служебный.

**как вернуть английский.** `/settings-language en` и заново открыть `/settings`. выбор языка никуда не записывается — следующая сессия снова стартует на русском, пока плагин установлен.

**как удалить.** `omp plugin uninstall omp-settings-ru`. для немедленного эффекта в текущей сессии сначала выполни `/settings-language en`; новая сессия без плагина всегда английская.

**повлияет ли это на мои модели и конфиги.** нет. перевод меняет только отображаемые подписи; значения, идентификаторы, провайдеры и файлы конфигурации не трогаются.
