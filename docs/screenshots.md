## Идентичность окружения

Native executable получен как GitHub asset **684983859** для поддержанного pinned host, проверен через `selectFixedHostAsset` / `verifyFixedHostBytes`. Фактический `--version`: `omp/18.13.3`; размер **244978176 байт**; повторно измеренный SHA-256: `ce97a82dc767f4cf5683ad17e08f095a27de9a15208dc702668cce24feb1b4fb`.

Запуск выполнен существующим `scripts/capture-installed-host.ts <verified-executable> omp-settings-ru-proof-20261028-visible <checkout>`. Helper связывает plugin с временным профилем и передаёт дочернему процессу только системные переменные из allowlist и изолированные HOME/USERPROFILE/APPDATA/LOCALAPPDATA; личная сессия, provider credentials и инструменты не подключаются. Для этих кадров отдельный smoke receipt не создавался: доказательство панели — реальные пиксели, а не результат тестового рендера.

Источник plugin — **неопубликованное незакоммиченное рабочее дерево**, версия package `0.10.0`. Canonical package content hash, измеренный существующим `canonicalContentHash` после съёмки в **2026-10-28T18:51:28.772Z**: `d09ef41f28353d3de5d24e787d71cc1480d26fdf8eb79695d8468afe6e5fa18c`. Он охватывает `package.json` и package files allowlist в момент измерения; это не commit SHA, не release archive hash и не доказательство неизменности всего рабочего дерева с момента старта процесса.
