# глоссарий перевода

Единые русские соответствия для терминов OMP, у которых нет устоявшегося перевода. При добавлении новых строк сверяйся с этой таблицей, а не переводи с нуля. Технические идентификаторы, значения вариантов, команды, переменные окружения и пути не переводятся никогда.

| термин | перевод | комментарий |
| --- | --- | --- |
| steering (live steering) | управление | устоявшийся термин протокола; кальку «руление» не использовать |
| prewalk | prewalk | имя механизма, латиницей |
| recap | сводка | краткое резюме сессии |
| loop guard | защита от циклов | |
| judge (ttsr, find) | судья | «правила с судьёй», «судья включён» — по контексту |
| completion probe | проверка завершённости | фоновый опрос subagent о прогрессе |
| hillclimb | hillclimb | имя алгоритма, латиницей |
| prelude | преамбула | загружаемый предмодуль |
| wrap-up steering notice | уведомление-указание о завершении | составной термин task-бюджета |
| friction-gated | создаваемый по трению | файлы решений, появляющиеся при «трении» рабочего процесса |
| recall / retain | выборка / сохранение | операции памяти Mnemopi/Hindsight |
| debounce | подавление дребезга | задержка перед реакцией на серию событий |
| reflink | рефлинк | copy-on-write копия; уточнять механизм: clonefile (APFS), FICLONE (Linux), блочное клонирование |
| cache warming (streaming / idle) | прогрев кэша (потоковый / в простое) | названия режимов — по смыслу, не транслит |
| snapcompact | Snapcompact | имя функции, латиницей |

| fallback | откат / резерв | `fallback` — откат на резервную модель; `server-side fallback` — серверный откат |
| supervision | контроль | наблюдение advisor за сессией |

## единицы и числа

KB/МБ/ГБ локализуются (КБ/МБ/ГБ), формат `1.5x` сохраняется как в источнике. Проценты, пороги токенов (`200K`), интервалы (`5m`, `1h` в подписях вариантов) — дословно.
