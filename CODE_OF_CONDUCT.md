# нормы поведения

Мы заинтересованы в спокойной технической дискуссии: по существу, с фактами и без перехода на личности.

## ожидаем

- уважительное общение в issues и pull request;
- воспроизводимые примеры вместо общих жалоб;
- готовность принять «нет» по запросам вне границ проекта (только панель `/settings`).

## недопустимо

- оскорбления, травля, дискриминация;
- публикация чужих личных данных, ключей и содержимого сессий;
- спам и реклама.

## последствия

Мейнтейнер может скрыть комментарий, закрыть обсуждение или заблокировать участника при повторных нарушениях. Вопросы — через issues.
